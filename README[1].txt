CERTIFICATE COLLECTION WEBSITE

Files:
- index.html: the complete website. All 6 certificate links are already added.

Deploy on Vercel:
1. Go to https://vercel.com and sign in.
2. Create a new project and import/upload this project folder (or push it to a Git repository).
3. No build command is required; this is a static HTML website.
4. Set the output directory to the project root if prompted, then deploy.
5. Vercel will provide a public URL to share.

Alternative quick deployment:
- You can upload the project to a GitHub repository and import that repository into Vercel.

Note: This ZIP contains the webpage, not copies of the certificates. Each button opens the original certificate URL.
